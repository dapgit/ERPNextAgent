# Code of Conduct

## Our Commitment

We are committed to fostering a welcoming, inclusive, and respectful environment for everyone who contributes to ERPNextAgent.

This project exists to help developers learn how to build enterprise AI applications using Google's Antigravity SDK and ERPNext. We value respectful collaboration, curiosity, and continuous learning.

---

# Our Standards

Examples of behaviour that contributes to a positive community include:

- Being respectful and professional.
- Providing constructive feedback.
- Helping others learn.
- Being open to different viewpoints.
- Accepting constructive criticism.
- Sharing knowledge and experience.

Examples of unacceptable behaviour include:

- Harassment or discrimination.
- Personal attacks or insults.
- Trolling or inflammatory comments.
- Publishing private information without permission.
- Any behaviour that creates an unsafe environment.

---

# Engineering Principles

When contributing to this repository:

- Prioritize maintainability over cleverness.
- Prefer readability over complexity.
- Document architectural decisions.
- Write code that future contributors can understand.

---

# Documentation

Documentation is considered part of the implementation.

A contribution is not complete until the related documentation has been updated.

---

# Reporting Issues

If you experience unacceptable behaviour, please open a private issue or contact the project maintainers.

All reports will be reviewed respectfully and handled confidentially whenever possible.

---

# Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

They may remove or reject contributions that violate these standards.
