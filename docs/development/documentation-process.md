# Documentation Process

Start from the documentation index and update canonical pages rather than duplicating content. Use the style guide’s metadata, relative links, status labels, navigation, and revision history. Link a decision to its ADR and a sprint outcome to its journal.

At sprint close, verify that README, roadmap, changelog, architecture pages, ADRs, journals, and indexes agree on what is complete, planned, or deferred. Record gaps in the documentation audit instead of silently treating them as complete.
