# Definition of Done

A change is complete when it is implemented in its owning layer, reviewed, verified at the appropriate level, and documented accurately. Architectural changes require an ADR where applicable. Sprint work requires its journal, changelog, architecture/index updates, and a clear record of deferred scope.

For integrations, completion also requires secure configuration, tested error behavior, and controlled end-to-end evidence. A plan, a diagram, or a placeholder is not completion evidence.
