# Policies and System Instructions

System instructions guide the agent’s interaction style and tool use; they do not replace application authorization or ERP permissions. Prompts should tell the agent to use capabilities accurately, handle uncertainty safely, and avoid exposing implementation or credential details.

Keep instructions centralized and reviewed with tool changes. Enforce access control in services and ERPNext, where it can be tested and audited.
