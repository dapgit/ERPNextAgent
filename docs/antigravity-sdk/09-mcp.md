# MCP

Model Context Protocol integration is not implemented in ERPNextAgent. It may become useful when external, separately managed capability providers are needed, but it must not erode the project’s service and repository boundaries.

Evaluate any MCP server for authentication, tool scope, schema quality, availability, auditability, data handling, and failure isolation. Record adoption in an ADR before production use.
