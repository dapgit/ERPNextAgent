# Introduction

This handbook explains how ERPNextAgent uses an agent runtime while preserving application ownership of business behavior. It is a project guide, not a substitute for the SDK reference for the installed version.

The central rule is simple: the runtime reasons over prompts and registered capabilities; application layers own policy, workflows, and data access.

## Reading path

Read this chapter first, then [runtime](02-runtime.md), [agents](03-agents.md), [tools](04-tools.md), and the remaining lifecycle and extension chapters. Each planned or version-sensitive feature is labelled rather than represented as current implementation.
