# Learning Path

## Overview

ERPNextAgent follows an incremental learning approach.

Each sprint introduces one major concept.

---

# Phase 1 – Foundations

Sprint 1

Learn:

- Python Environment
- Antigravity SDK
- Gemini
- First Agent

---

# Phase 2 – AI Tools

Sprint 2

Learn:

- Tool Registration
- Tool Invocation
- Tool Metadata
- AI Capabilities

---

# Phase 3 – Application Architecture

Sprint 3

Learn:

- Interactive CLI
- Configuration
- Application Lifecycle
- Agent Management

---

# Phase 4 – Enterprise Architecture

Sprint 4

Learn:

- Repository Pattern
- Service Layer
- Domain Models
- Layered Architecture

---

# Phase 5 – ERPNext Integration

Sprint 5

Learn:

- REST APIs
- Authentication
- Repository Implementation
- Error Handling

---

# Phase 6 – Advanced AI

Future learning includes:

- Memory
- MCP
- Multi-Agent Systems
- Production Deployment
