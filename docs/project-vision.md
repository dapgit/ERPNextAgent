# Project Vision

## Vision Statement

To build a production-quality AI Assistant for ERPNext using Google's Antigravity SDK while documenting every architectural decision, implementation detail, and lesson learned.

The project is intended to be both:

- A working enterprise AI application.
- A comprehensive learning resource.

---

# Objectives

The project has five primary objectives.

## 1. Learn Antigravity SDK

Understand how to build AI agents using:

- Agents
- Tools
- Conversations
- Hooks
- Triggers
- MCP
- Gemini Models

through practical implementation.

---

## 2. Build an Enterprise AI Assistant

The assistant should eventually support:

- Customer queries
- Company information
- Inventory
- Sales Orders
- Purchase Orders
- Financial reports

using ERPNext as the backend.

---

## 3. Demonstrate Professional Software Engineering

The repository should showcase:

- Layered Architecture
- Repository Pattern
- Domain Models
- Service Layer
- Documentation
- Testing
- Refactoring

---

## 4. Documentation First

Documentation evolves with the code.

Every sprint updates:

- README
- ADRs
- Sprint Journal
- Architecture
- Roadmap

---

## 5. Learn by Building

Every new concept should be introduced through implementation rather than isolated examples.

---

# Success Criteria

The project will be considered successful if a new developer can:

1. Clone the repository.
2. Read the documentation.
3. Understand the architecture.
4. Run the application.
5. Extend it with new ERPNext functionality.
