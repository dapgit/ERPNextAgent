# Support

ERPNextAgent is an educational, in-progress project. This page explains where to get help and what kind of help to expect.

## Before asking

1. Read the [README](README.md) for the project vision and quick start.
2. Check [docs/index.md](docs/index.md) for the full documentation map — architecture, ADRs, sprint journals, and handbooks.
3. Check [docs/project-roadmap.md](docs/project-roadmap.md) to see whether the feature or behaviour you're asking about is already marked planned rather than implemented.
4. Search existing GitHub issues for the same question before opening a new one.

## Where to get help

| Need | Where |
| --- | --- |
| Bug report | Open a GitHub issue with reproduction steps |
| Feature idea or design discussion | Open a GitHub issue tagged `discussion` |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md) — do not open a public issue |
| Contribution / PR question | See [CONTRIBUTING.md](CONTRIBUTING.md) |

## What is in scope

- Questions about the current architecture (agent → tool → service → repository).
- Questions about why a decision was made — check the [ADRs](docs/adr/index.md) first, they usually already answer "why."
- Questions from people learning the Antigravity SDK alongside this project.

## What is out of scope

- Requests to prioritize ERPNext integration ahead of the documented roadmap — see [docs/project-roadmap.md](docs/project-roadmap.md).
- General ERPNext support unrelated to this project's integration layer; use ERPNext's own community channels for that.

## Response expectations

This is a learning project maintained on a best-effort basis, not a commercially supported product. There is no guaranteed response time.
